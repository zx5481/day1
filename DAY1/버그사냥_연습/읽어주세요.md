# 버그사냥_연습 (1일차 6교시)

가상의 감귤 농가 「돌담귤방」 상품 페이지의 계산 함수에 **버그 3개**가 숨어 있어요. 오늘 필수는 1개예요.

1. 이 폴더를 Claude 데스크톱 앱 Code 탭에서 엽니다. (내 프로젝트 폴더와 다른 폴더!)
2. `node --test` 를 실행하면 **통과 5 · 실패 3** 이 나옵니다.
3. 교안의 4단계(재현 → 원인 가설 → 최소 수정 → 회귀 테스트)로 잡으세요.
   - **필수 — 버그 1(예산 경계):** 다 함께 잡아요. 고치면 **통과 6 · 실패 2** 가 됩니다.
   - **도전 — 버그 2(큰 금액) · 버그 3(해를 넘기는 제철):** 빠른 사람만 혼자 잡아요. 다 잡으면 **실패 0**.
4. **test 폴더의 파일은 고치지 않습니다** — 테스트는 사람이 정한 기준이에요.

- 화면 확인: index.html 을 Browser 패널로 열기 (파일을 그냥 더블클릭해도 열립니다)
- 상품 · 가격 · 제철은 강의용 가상의 예시 값입니다.
- 교안의 ‘시작 — git · 첫 실행’ 프롬프트로 첫 커밋을 해 두면, 고친 것마다 커밋으로 남길 수 있어요.
