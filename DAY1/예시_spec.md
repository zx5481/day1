# spec.md — 상품 목록 페이지 (예시 · 돌담귤방)

> 1일차 3교시 예시입니다. 완료 기준은 **예/아니오로 확인할 수 있게** 씁니다.

## 목표 (한 줄)
손님이 휴대폰에서 상품을 한눈에 보고, 이번 달 제철과 예산에 맞는 선물을 바로 고를 수 있다.

## 기능 3개
1. **상품 카드 목록** — 이름 · 가격 · 태그 · 한 줄 설명
2. **이번 달 제철 표시** — 오늘 날짜의 달이 상품의 제철이면 ‘제철’ 표시
3. **예산으로 선물 고르기** — 예산을 넣으면 예산 이하 상품 중 비싼 순 최대 3개

## 화면 (글로 그린 와이어프레임)
```
[ 돌담귤방 · 이번 달: 1월 ]
[ 예산(원) ______ ] [추천]
추천 ─ 카드 3개
전체 상품 ─ 카드 목록 (제철 표시)
```

## 데이터 모양 — products.json
```json
{ "id": "gyul-5", "name": "노지감귤 5kg", "price": 29000,
  "season": { "from": 11, "to": 2 }, "tags": ["기본"], "desc": "새콤달콤 기본 귤" }
```
- price: 원 단위 정수
- season: 제철 시작 달 ~ 끝 달. from > to 이면 해를 넘김(11월~2월). 연중 판매는 1~12.

## 완료 기준 (예/아니오)
1. 가격은 `29,000원` 처럼 쉼표와 ‘원’으로 보인다 — 1,234,567원 같은 큰 금액도.
2. 제철이 11월~2월인 상품은 1월에 ‘제철’, 3월에는 표시가 없다.
3. 예산이 30000원이면 정확히 30000원인 상품도 추천에 들어간다.
4. 예산이 가장 싼 상품보다 작으면 ‘이 예산에 맞는 상품이 없어요’ 안내가 보인다.
5. 휴대폰 폭 390px 에서 가로 스크롤이 생기지 않는다.
6. 키보드 Tab 만으로 예산 입력 → 추천 버튼까지 갈 수 있다.

## 이번에 하지 않을 것
결제 · 로그인 · 장바구니 · 실제 시세(5일차에 공공데이터로)

> 상품 · 가격 · 제철은 가상의 예시 값입니다.
